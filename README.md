# Machine Learning Resources

A personal collection of machine-learning study materials, course resources,
lecture notes, notebooks, datasets, cheatsheets, and reference books.

## What's included

- **CSE 445 course materials**: lectures, course outlines, project templates,
  practical notebooks, cheatsheets, and datasets.
- **Machine Learning by Andrew Ng**: selected course slides, lab notebooks, and
  supporting Python files.
- **Textbooks and references**: machine-learning and deep-learning books,
  lecture slides, and supplementary material.
- **Cheatsheets**: quick references for supervised learning, unsupervised
  learning, deep learning, statistics, probability, and related topics.

The folders are grouped by course, source, or subject. Some filenames and
folder names are retained as provided by the original source.

## Getting started

Most notebooks can be opened with Jupyter Notebook, JupyterLab, or VS Code
with the Jupyter extension. Python examples generally use common scientific
Python packages such as NumPy, pandas, Matplotlib, and scikit-learn.

Because the materials come from different courses and sources, each notebook
may require its own dependencies. Check the notebook imports and the
accompanying course notes before installing packages or running code.
